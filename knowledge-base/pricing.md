# Subscription Plans & Pricing

## Starter Plan — $29/month

- Up to 5 team members
- 10GB storage
- Email support (48-hour response time)
- Basic analytics dashboard
- Single workspace
- Monthly billing only

## Professional Plan — $79/month

- Up to 25 team members
- 100GB storage
- Priority email support (24-hour response time)
- Advanced analytics with custom reports
- Up to 5 workspaces
- Monthly or annual billing (annual saves 20%)
- API access (1,000 requests/day)
- Custom integrations

## Enterprise Plan — $199/month per seat (minimum 10 seats)

- Unlimited team members
- 1TB storage per seat
- Dedicated account manager
- Phone and email support (4-hour response time)
- Unlimited workspaces
- Custom billing arrangements
- Full API access (unlimited requests)
- SSO/SAML authentication
- 99.9% uptime SLA
- Custom data retention policies

## Add-ons

- Additional storage: $5/month per 50GB
- Additional API requests: $10/month per 5,000 requests/day
- Premium support upgrade: $49/month (adds phone support to any plan)

## Plan Changes

- Upgrades take effect immediately; you are charged a prorated amount
  for the remainder of the current billing period.
- Downgrades take effect at the start of the next billing period.
  You retain access to higher-tier features until then.
- Plan changes can be made at any time from the account settings
  page or by contacting support.
